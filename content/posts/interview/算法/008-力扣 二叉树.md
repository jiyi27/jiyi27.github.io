## 617 合并二叉树

```c#
public TreeNode MergeTrees(TreeNode root1, TreeNode root2) {
    TreeNode tempNode = new TreeNode();
    if (root1 == null && root2 == null) {
        return null;
    }

    if (root1 != null && root2 != null) {
        tempNode.left = MergeTrees(root1.left, root2.left);
        tempNode.right = MergeTrees(root1.right, root2.right);
        tempNode.val = root1.val + root2.val;
    }
    else if (root1 == null && root2 != null) {
        tempNode.left = MergeTrees(null, root2.left);
        tempNode.right = MergeTrees(null, root2.right);
        tempNode = root2;
    }
    else if (root1 != null && root2 == null) {
        tempNode.left = MergeTrees(root1.left, null);
        tempNode.right = MergeTrees(root1.left, null);
        tempNode = root1;
    }
    return tempNode;
}
```

```c#
public TreeNode MergeTrees(TreeNode root1, TreeNode root2) {
    // 如果其中一个节点为空，直接返回另一个节点
    if (root1 == null) return root2;
    if (root2 == null) return root1;
    
    // 两个节点都不为空时，合并值并递归处理子节点
    TreeNode merged = new TreeNode(root1.val + root2.val);
    merged.left = MergeTrees(root1.left, root2.left);
    merged.right = MergeTrees(root1.right, root2.right);
    
    return merged;
}
```





## 543 二叉树直径 

结合简单场景理解一下就好了: 

```
    1
   / \
  2   3
```

```c#
public class Solution {
    private int maxDiameter = 0;
    
    public int DiameterOfBinaryTree(TreeNode root) {
        GetHeight(root);
        return maxDiameter;
    }
    
    // 返回以root为根的子树的高度，同时更新全局最大直径
    private int GetHeight(TreeNode root) {
        if (root == null) {
            return 0;
        }

        var leftHeight = GetHeight(root.left);
        var rightHeight = GetHeight(root.right);
        
        // 更新全局最大直径
        var currentDiameter = leftHeight + rightHeight;
        maxDiameter = Math.Max(currentDiameter, maxDiameter);

        return Math.Max(leftHeight, rightHeight) + 1;
    }
}
```

容易写错的地方:

```c#
// 返回以root为根的子树的高度，同时更新全局最大直径  
private int GetHeight(TreeNode root) {
    if (root == null) {
        return 0; // 空节点高度为0
    }
    var leftHeight = GetHeight(root.left) + 1;  // ❌ 提前+1
    var rightHeight = GetHeight(root.right) + 1; // ❌ 提前+1
    
    // 更新全局最大直径
    var currentDiameter = leftHeight + rightHeight; // ❌ 导致直径计算错误 多加2
    maxDiameter = Math.Max(currentDiameter, maxDiameter);
    return Math.Max(leftHeight, rightHeight);
}
```

这种方法对返回值没什么影响, 但影响了直径的计算, 导致直径总是比正确结果大 2

**为什么直径只大 2，而不是累积？** 

`maxDiameter` 是全局变量, 只记录所有 `currentDiameter` 的最大值, 每次递归调用, `currentDiameter` 都会比正确值多 2, 但这不会因树的高度或层数累积（即不会变成 `n*2`）, 因为 `maxDiameter` 只取单次最大值, 下面这样写也是正确的, 但显然没有第一种方法省事

```c#
public class Solution {
    private int maxDiameter = 0;
    
    public int DiameterOfBinaryTree(TreeNode root) {
        GetHeight(root);
        return maxDiameter - 2;
    }
    
    // 返回以root为根的子树的高度，同时更新全局最大直径
    private int GetHeight(TreeNode root) {
        if (root == null) {
            return 0;
        }

        var leftHeight = GetHeight(root.left) + 1;
        var rightHeight = GetHeight(root.right) + 1;
        
        // 更新全局最大直径
        var currentDiameter = leftHeight + rightHeight;
        maxDiameter = Math.Max(currentDiameter, maxDiameter);

        return Math.Max(leftHeight, rightHeight);
    }
}
```
