     for dest, src in prerequisites:

`adjacency` 是一个 `defaultdict` 类型的数据结构

`defaultdict` 是 Python 标准库 `collections` 模块中的一个类，它继承自 `dict`（字典），但增加了一个特性：当你访问一个不存在的键时，它**不会引发 `KeyError`**，而是会自动创建一个默认值

> 如果我想实现 记录每个数字出现的次数 是不是 `defaultdict` 也很合适
>
> 当使用 `defaultdict(int)` 时，如果你访问一个不存在的键，它会自动为该键创建一个默认值 `0`
>
> ```python
> from collections import defaultdict
> 
> numbers = [1, 2, 3, 2, 1, 4, 1]
> count_map = defaultdict(int)
> 
> for number in numbers:
>  count_map[number] += 1
> ```

```python
queue = deque([i for i in range(numCourses) if in_degree[i] == 0])
```

等价于

```python
queue = []
for i in range(numCourses):
    if in_degree[i] == 0:
        queue.append(i)
```

> 为什么上面的 queue = [] 而不是 `deque()`,  有什么区别?
>
> - `list` (`[]`)：列表在内存中是连续存储的, 当你想从列表的**开头**删除一个元素时（`pop(0)`），Python 必须将后面的所有元素都向前移动一位来填补空缺, 这种操作的效率是 **O(n)**（线性时间）
> - `deque` (`deque()`)：`deque`（双端队列）是专门为快速地在两端添加和删除元素而设计的, 在内部实现为双向链表，所以从队列的两端添加（`append`）或删除（`popleft`）元素时，不需要移动其他元素
>   - 这种操作的效率是 **O(1)**（常数时间）
>
> 使用 `list` 作为队列（不推荐）
>
> ```python
> queue = []
> queue.append(1)  # 头部添加，O(1)
> queue.append(2)
> first_item = queue.pop(0)  # 头部删除，非常慢！ O(n)
> ```
>
>  使用 `deque` 作为队列（推荐）
>
> ```python
> queue = deque()
> queue.append(1)  # 尾部添加，O(1)
> queue.append(2)
> first_item = queue.popleft()  # 头部删除，非常快！ O(1)
> ```

A stack can be easily simulated using a Python list because appending and popping from the end of a list is efficient (O(1) time).

```python
# Simulating a stack using a list
stack = []

# Push elements
stack.append(1)  # Stack: [1]
stack.append(2)  # Stack: [1, 2]
stack.append(3)  # Stack: [1, 2, 3]
print("Stack after pushes:", stack)

# Pop element
top = stack.pop()  # Removes 3, Stack: [1, 2]
print("Popped:", top)
print("Stack after pop:", stack)

# Peek at top
if stack:
    print("Top element:", stack[-1])  # Prints 2

# Check if empty
print("Is stack empty?", len(stack) == 0)  # False

# Pop remaining elements
while stack:
    print("Popped:", stack.pop())  # Pops 2, then 1
print("Is stack empty?", len(stack) == 0)  # True
```

A queue is best implemented using collections.deque because it provides O(1) time complexity for adding and removing elements from both ends. Using a list for a queue is less efficient for dequeuing (O(n) for pop(0)).

```python
from collections import deque

# Simulating a queue using deque
queue = deque()

# Enqueue elements
queue.append(1)  # Queue: [1]
queue.append(2)  # Queue: [1, 2]
queue.append(3)  # Queue: [1, 2, 3]
print("Queue after enqueues:", queue)

# Dequeue element
front = queue.popleft()  # Removes 1, Queue: [2, 3]
print("Dequeued:", front)
print("Queue after dequeue:", queue)

# Peek at front
if queue:
    print("Front element:", queue[0])  # Prints 2

# Check if empty
print("Is queue empty?", len(queue) == 0)  # False

# Dequeue remaining elements
while queue:
    print("Dequeued:", queue.popleft())  # Dequeues 2, then 3
print("Is queue empty?", len(queue) == 0)  # True
```
