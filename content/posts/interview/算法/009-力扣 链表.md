## [142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)

不理解可以看看代码随想录的讲解视频

```c#
/**
 * 算法原理说明：
 *
 * 1. 第一阶段 - 检测环的存在：
 *    - 使用快慢指针，快指针每次走2步，慢指针每次走1步
 *    - 如果有环，快指针最终会追上慢指针
 *    - 如果没有环，快指针会先到达链表末尾
 *
 * 2. 第二阶段 - 找到环的起始点：
 *    - 设链表头到环起始点的距离为 a
 *    - 设环起始点到快慢指针相遇点的距离为 b
 *    - 设相遇点到环起始点的距离为 c
 *    - 那么环的长度为 b + c
 *
 *    当快慢指针相遇时：
 *    - 慢指针走过的距离：a + b
 *    - 快指针走过的距离：a + b + n(b + c) （n为快指针多走的圈数）
 *    - 由于快指针速度是慢指针的2倍：2(a + b) = a + b + n(b + c)
 *    - 化简得：a + b = n(b + c)
 *    - 进一步化简：a = n(b + c) - b = (n-1)(b + c) + c
 *
 *    这意味着从链表头走 a 步到达环起始点，
 *    等于从相遇点走 (n-1) 圈再加 c 步也到达环起始点。
 *    当 n = 1 时，a = c，即从头节点和相遇点同时出发，
 *    以相同速度移动，相遇点就是环的起始点。
 */
public ListNode? DetectCycle(ListNode? head) {
    var fast =  head;
    var slow = head;

    while (fast != null && fast.Next != null)
    {
        // 慢指针走一步, 快指针走两步
        fast = fast.Next.Next;
        slow = slow?.Next;
        // 存在环, 找环的起始节点
        if (fast == slow)
        {
            // 将其中一个指针重置到头节点，两个指针以相同速度移动
            fast = head;
            while (fast != slow)
            {
                fast = fast?.Next;
                slow = slow?.Next;
            }
            return slow;
        }
    }
    return null;
}
```

## 141 环形链表

想一想临界值, 比如快指针落后慢指针两步, 三步, 可以推理出, 快指针不可能会跳过慢指针, 他们一定会相遇, 因为快指针只是比慢指针快一步, 每次都是接近一步, 不会一下跳过慢指针

```c#
// 慢指针速度：1步/轮, 快指针速度：2步/轮, 相对速度差：2-1 = 1步/轮
// 这意味着：每一轮，快指针都恰好向慢指针靠近1步, 不是2步、3步或其他，就是1步
// 如果距离 > 1：快指针靠近1步，但还没追上
// 如果距离 = 1：快指针靠近1步，刚好追上
// 不存在'跳过'的情况
public bool HasCycle2(ListNode? head)
{
    if (head == null || head.Next == null) 
    {
        return false;
    }

    // 慢指针每次移动1步
    var slow = head;
    // 快指针每次移动2步
    var fast = head;

    while (fast != null && fast.Next != null)
    {
        slow = slow?.Next;
        fast = fast.Next.Next;
        if (slow == fast)
        {
            return true;
        }
    }
    return false;
}

public bool HasCycle1(ListNode? head)
{
    var seen = new HashSet<ListNode>();
    while (head != null)
    {
        if (!seen.Add(head))
        {
            return true;
        }
        head = head.Next;
    }
    return false;
}
```
