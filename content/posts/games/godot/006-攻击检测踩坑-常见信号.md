## 1. 节点结构

### 1.1. 敌人

```
Stone (Node2D)
 - AnimatedSprite2D
 - StaticBody2D
    - CollisionShpe2D
```

- 其中 StaticBody2D 的 layer 为 2
  - layer 用于被玩家武器 area 检测到, 触发武器的 `body_entered` 信号, 石头 mask 不用指定, 因为是否不会主动检测其他物体

### 1.2. 玩家

```
Player (CharacterBody2D)
    - BaseSprite (AnimatedSprite2D)
    - HairSprite (AnimatedSprite2D)
    - WeaponArea (Area2D)
        - CollisionShpe2D
    - CollisionShpe2D
```

- `WeaponArea` 的 layer 为 3, mask 为 1, 2 
  - 用于攻击敌人
- `Player` 的 layer 为 3, mask 为 1, 2 
  - 用于检测地图碰撞

## 2. 脚本不要挂错节点

脚本是挂在节点上的, 并不是随便一个脚本都可以挂在任意节点上, 一个脚本可以挂在多个节点上, 但是要看节点的类型是脚本最开始生命的 `extends CharacterBody2D`, `extends StaticBody2D` 等这种类型

假如有一个石头, 石头的节点组成为

```
Node2D
 - AnimatedSprite2D
 - StaticBody2D
    - CollisionShpe2D
```

则处理 `take_damage` 相关逻辑的脚本应该挂在 `StaticBody2D` 上, 而不是 `Node2D`, 因为玩家的脚本一半有类似下面这样的处理:

```js
func _ready():
	weapon_area.monitoring = false
	# 正确连接攻击命中信号
	weapon_area.body_entered.connect(_on_attack_hit)
	base_sprite.animation_finished.connect(_on_attack_finished)
	# 连接帧变化信号来控制武器区域的激活
	base_sprite.frame_changed.connect(_on_frame_changed)

# 处理帧变化，在特定帧激活武器区域
func _on_frame_changed():
	if base_sprite.animation == "attack" and base_sprite.frame == ATTACK_FRAME:
		weapon_area.monitoring = true
	elif base_sprite.animation == "attack" and base_sprite.frame != ATTACK_FRAME:
		weapon_area.monitoring = false

func _on_attack_hit(body: Node) -> void:
	print("命中了:", body.name)
	if body.has_method("take_damage"):
		body.take_damage(1)
```

其中 `weapon_area.body_entered`  信号由石头的物理节点 `StaticBody2D` 触发, 而不是其根节点 `Node2D`, 因此若脚本绑定在了 `Node2D` 上, 就会出现 `_on_attack_hit` 执行了, 可是 石头的 `take_damage()` 没有被调用, 因为 脚本绑定在了 `Node2D`, 而 `StaticBody2D` 并没有 `take_damage()` 函数, 所以 `body.has_method("take_damage")` 为 `false`

## 3. 脚本的节点引用要注意路径

下面这段代码出现了错误

```js
func take_damage(damage: int = 1) -> void:
	if health <= 0:
		return
	health -= damage
	if health > 0:
	  # 这里出现了错误
	  # Invalid access to property or key 'animation' on a base object of type 'null instance'.
		if anim.animation != "hit" and anim.animation != "break":
			anim.play("hit")
	else:
		if collider:
			collider.disabled = true
		anim.play("break")
		await anim.animation_finished
		_on_break_finished()
```

显然 说明 `anim` 变量是 `null`, 可以看一下 `anim` 的声明:

```js
@onready var anim: AnimatedSprite2D = $AnimatedSprite2D
```

我们的节点结构是:

```
Node2D
 - AnimatedSprite2D
 - StaticBody2D
    - CollisionShpe2D
```

脚本绑定的是 `StaticBody2D`

所以正确的声明应该是:

```js
@onready var anim: AnimatedSprite2D = $"../AnimatedSprite2D" 
```

## 4. 代码

实现攻击的逻辑是, 直接为角色添加一个 Area2D, 然后看一下攻击动画大概攻击的位置, 然后把 Area2D 的 CollisionShape2D 形状放到那里, 平时此 Area2D 节点的 monitoring 被禁用, 只有在播放攻击动画且到武器挥出那一帧时才被允许检测, 这样就实现了挥出剑挥砍敌人的效果, 是一个偷懒的方法

### 4.1. 石头脚本 (绑定在 StaticBody2D 节点)

```js
extends StaticBody2D
@export var max_health: int = 3
var health: int
@onready var anim: AnimatedSprite2D = $"../AnimatedSprite2D" 
@onready var collider: CollisionShape2D = $StaticBody2D/CollisionShape2D

func _ready():
	health = max_health
	# 连接动画完成信号
	anim.animation_finished.connect(_on_animation_finished)

func take_damage(damage: int = 1) -> void:
	if health <= 0:
		return
	health -= damage
	
	print("被攻击了")
	if health > 0:
		if anim.animation != "hit" and anim.animation != "break":
			anim.play("hit")
	else:
		if collider:
			collider.disabled = true
		anim.play("break")
		await anim.animation_finished
		_on_break_finished()

# 处理动画完成后的逻辑
func _on_animation_finished():
	if anim.animation == "hit" and health > 0:
		anim.play("idle")

func _on_break_finished():
	queue_free()
```

> `anim.animation_finished` 是一个信号, 在 Godot 中, `AnimatedSprite2D` 节点有一个内置的信号叫 `animation_finished`, 当动画播放完成时会自动发出这个信号
>
> ```python
> # animation_finished 是 AnimatedSprite2D 的内置信号
> # 当任何动画播放完毕时都会发出这个信号
> 
> # 连接信号的语法：
> 信号发射者.信号名.connect(接收函数)
> 
> # 在我们的例子中：
> anim.animation_finished.connect(_on_animation_finished)
> # 意思是：当 anim 的动画播放完成时，调用 _on_animation_finished 函数
> ```
>
> AnimatedSprite2D 的常用信号：
>
> ```python
> # animation_finished - 动画播放完成时发出
> anim.animation_finished.connect(_on_animation_finished)
> 
> # animation_changed - 动画切换时发出  
> anim.animation_changed.connect(_on_animation_changed)
> 
> # frame_changed - 动画帧改变时发出
> anim.frame_changed.connect(_on_frame_changed)
> ```

### 4.2. 玩家脚本

```js
extends CharacterBody2D

const SPEED = 200.0
@onready var base_sprite: AnimatedSprite2D = $BaseSprite
@onready var hair_sprite: AnimatedSprite2D = $HairSprite
@onready var weapon_area: Area2D = $WeaponArea
var is_attacking = false
const ATTACK_FRAME = 3

func _ready():
	weapon_area.monitoring = false
	weapon_area.body_entered.connect(_on_attack_hit)
	base_sprite.animation_finished.connect(_on_attack_finished)
	# 连接帧变化信号来控制武器区域的激活
	base_sprite.frame_changed.connect(_on_frame_changed)

func _physics_process(_delta):
	if is_attacking:
		return
	
	var direction = Input.get_vector(
		'ui_left', 'ui_right', 'ui_up', 'ui_down')
	
	if direction.length():
		velocity = direction * SPEED
		
		# 设置朝向
		if direction.x > 0:
			set_flip(false)
		elif direction.x < 0:
			set_flip(true)
		
		# 播放走路动画
		play_animation("walk")
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)
		velocity.y = move_toward(velocity.y, 0, SPEED)
		# 播放 idle 动画
		play_animation("idle")
	
	move_and_slide()

# 处理帧变化，在特定帧激活武器区域
func _on_frame_changed():
	if base_sprite.animation == "attack" and base_sprite.frame == ATTACK_FRAME:
		weapon_area.monitoring = true
	elif base_sprite.animation == "attack" and base_sprite.frame != ATTACK_FRAME:
		weapon_area.monitoring = false

func _input(event):
	if event.is_action_pressed("attack") and not is_attacking:
		attack()

# 处理攻击命中
func _on_attack_hit(body: Node) -> void:
	print("命中了:", body.name)  # 调试用
	if body.has_method("take_damage"):
		body.take_damage(1)  # 传递伤害值

func attack():
	is_attacking = true
	velocity = Vector2.ZERO
	play_animation("attack")

func _on_attack_finished():
	if base_sprite.animation == "attack":
		is_attacking = false
		weapon_area.monitoring = false
		update_animation()

func update_animation():
	if is_attacking:
		return
	var direction = Input.get_vector(
		'ui_left', 'ui_right', 'ui_up', 'ui_down')
	
	if direction.length():
		play_animation("walk")
	else:
		play_animation("idle")

# 同时控制两个 sprite 播放动画
func play_animation(name: String):
	base_sprite.play(name)
	hair_sprite.play(name)

# 同时控制两个 sprite 的朝向
func set_flip(flip_h: bool):
	base_sprite.flip_h = flip_h
	hair_sprite.flip_h = flip_h
```

Area2D 节点信号

```js
# 碰撞检测信号
area.body_entered.connect(_on_body_entered)       # 刚体进入
area.body_exited.connect(_on_body_exited)         # 刚体离开
area.area_entered.connect(_on_area_entered)       # 区域进入
area.area_exited.connect(_on_area_exited)         # 区域离开

# 使用场景：触发器，拾取道具，伤害区域
func _on_body_entered(body):
    if body.is_in_group("player"):
        print("玩家进入了商店区域")
        show_shop_ui()
```
