## 1. Godot 2D 角色移动过程 

```js
extends CharacterBody2D

const SPEED = 150.0
const JUMP_VELOCITY = -300.0

@onready var sprite: AnimatedSprite2D = $AnimatedSprite2D

func _physics_process(delta: float) -> void:
	# Add the gravity.
	if not is_on_floor():
		velocity += get_gravity() * delta

	# Handle jump.
	if Input.is_action_just_pressed("ui_accept") and is_on_floor():
		velocity.y = JUMP_VELOCITY

	# Get the input direction
	var direction := Input.get_axis("ui_left", "ui_right")

	# 水平移动
	if direction != 0:
		velocity.x = direction * SPEED
		# 设置动画为 run
		if sprite.animation != "run":
			sprite.play("run")
		# 水平翻转角色
		sprite.flip_h = direction < 0
	else:
		velocity.x = move_toward(velocity.x, 0, SPEED)
		# 设置动画为 idle
		if sprite.animation != "idle":
			sprite.play("idle")

	move_and_slide()
```

### 1.1. 物理帧更新 (`_physics_process`)

游戏引擎以固定的频率（通常是每秒 60 次，称为**物理帧**）调用脚本中的 `_physics_process(delta: float)` 函数

`delta` 参数代表了自上一帧以来经过的时间

### 1.2. 计算期望速度 (`velocity`)

在每一帧的 `_physics_process` 中，脚本会：

- 读取输入： 监听玩家的按键输入（例如，是否按下了左右方向键、跳跃键）
- 施加重力： 如果角色不在地面上，就会计算并累加重力对垂直速度 `velocity.y` 的影响，使其向下加速
- 处理玩家意图：
  - 跳跃： 如果玩家按下跳跃键且在地面上，脚本会瞬间设置 `velocity.y` 为一个向上的负值（例如 `-300`）
  - 水平移动： 如果玩家按住左右方向键，脚本会持续设置 `velocity.x` 为一个向左或向右的速度值（例如 `150` 或 `-150`）
  - 减速/停止： 如果**玩家松开左右方向键**，脚本会逐渐减小 `velocity.x`，使其**平滑地趋近于 `0`**，从而实现减速效果
- 最终，脚本会得到一个代表角色期望移动方向和速度的 `Vector2` 类型的 `velocity` 变量。这个 `velocity` 结合了所有水平和垂直方向上的作用力

### 1.3. 执行实际移动和碰撞 (`move_and_slide()`)

这是整个移动流程中**最关键**的一步，也是 `CharacterBody2D` 的核心功能：

- 在 `_physics_process` 函数的末尾，脚本会调用 `CharacterBody2D` 内置的 `move_and_slide()` 函数
- `move_and_slide()` 会读取**当前帧**计算出的 `velocity` 值，并乘以 `delta` 来确定角色在**当前这一帧**应该移动的**精确位移**
- 接着，引擎会尝试将角色实际移动到这个新的位置
- **智能碰撞处理：** 在移动过程中，`move_and_slide()` 会自动检测并处理角色与场景中其他碰撞体（如地面、墙壁）的交互, 它会确保角色不会穿透障碍物，而是沿着表面滑动，或者在撞到不可逾越的障碍时停止移动
- **更新速度状态：** `move_and_slide()` 还会根据碰撞结果，**自动修改** `CharacterBody2D` 内部的 `velocity` 属性（例如，当角色落地时，`velocity.y` 会被置为 `0`；撞墙时，对应的水平速度也会变为 `0`）, 它还会更新 `is_on_floor()` 等状态变量，供脚本判断

> **为什么按一下用户只移动一下？**
>
> ```js
> # Get the input direction
> var direction := Input.get_axis("ui_left", "ui_right")
> 
> # 水平移动
> if direction != 0: # 如果有输入（按下了左或右）
>     velocity.x = direction * SPEED # 设置速度
>     # ... 动画和翻转逻辑 ...
> else: # 如果没有输入（松开了左和右）
>     velocity.x = move_toward(velocity.x, 0, SPEED) # 逐渐减速到0
>     # ... 动画逻辑 ...
> ```
>
> 此脚本实现的是“按住持续移动，松开平滑减速”

> **总结**
>
> - `_physics_process` 每帧执行一次
>
> - `_physics_process` 处理的是监听用户输入逻辑, 所以可以理解为游戏每帧都会读取用户输入, 判断角色的移动方向 攻击等输入
> - `move_and_slide()` **读取** `CharacterBody2D` 自身的 `velocity` 属性, 它根据这个 `velocity` 和 `delta`（时间）来计算**当前帧**应该移动的距离，并更新角色的 `position`, 它不是判断“下一帧”的位置，而是执行“当前帧”的移动
